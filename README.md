# 🦷 Sonrisa Clínica Dental

Aplicación web full-stack educativa para una clínica dental ficticia en Santiago de Chile.

Stack: React + Vite + TypeScript + Tailwind CSS (frontend) · Node.js + Express + Prisma + SQLite (backend).

> Documentación completa de instalación, configuración, endpoints y solución de problemas en construcción (Fase 7).

## Estructura

```
dental-clinic/
├── frontend/   # SPA React (Vite, Tailwind, React Router)
├── backend/    # API REST (Express, Prisma, SQLite)
└── README.md
```
